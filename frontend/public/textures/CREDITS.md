# Texture credits

- `moon_1024.jpg` — real lunar imagery, bundled as an MIT-licensed example
  asset in the three.js repository (`examples/textures/planets/moon_1024.jpg`,
  https://github.com/mrdoob/three.js, MIT license), itself derived from NASA
  lunar basemap data. This is a real texture of the real Moon.
- `mars_1024.jpg` — NOT a photograph. This sandbox could not reach NASA.gov,
  Wikimedia Commons or Solar System Scope (outbound network here is
  restricted to GitHub + package registries), and the one conveniently
  reachable GitHub-hosted Mars texture credits a third-party source whose
  redistribution terms weren't clear enough to use here. Generated instead
  with `scripts/make_mars_texture.py` (fractal noise, craters, polar caps) —
  an original, zero-licensing-risk stand-in. Labelled in the UI as a
  synthetic rendering, same rule as every other illustration in this project.
